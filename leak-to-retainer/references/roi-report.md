# Leak-to-Retainer — Monthly ROI Report Template

Generate a one-page report for every client, every month. Lead with the biggest number.

```
[BUSINESS NAME] — MONTHLY ROI REPORT
[Month Year]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
THE BIG NUMBER
$[X] in revenue protected this month
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CALLS CAUGHT
• Total calls answered: [X]
• After-hours calls caught: [Y] ([Z]% of total)
• Calls that would have gone to voicemail/competitor: [Y]

APPOINTMENTS BOOKED
• Direct bookings into calendar: [X]
• Emergency dispatches: [Y]
• Average booking value: $[Z]

VS. THE OLD WAY
• Previous solution: [receptionist / voicemail / nothing]
• Previous monthly cost: $[X]
• Previous coverage: [9–5 / missed after-hours / etc.]
• Cost per call handled: $[Y] (old) vs. $[Z] (AI)

THIS MONTH'S WINS
• [Specific story: "Friday 8:47 PM — booked $4,200 emergency HVAC"]
• [Customer quote if available]

NEXT MONTH
• Suggested upgrade: [add Spanish / add SMS follow-up / expand hours]
• Projected additional revenue: $[X]
```

## Report Rules
- Lead with revenue protected — never lead with "calls answered"
- Include at least one specific story with time, value, and outcome
- Compare to their old cost (receptionist salary, missed jobs, etc.)
- Always end with an upsell suggestion
- Send by email + SMS to owner
