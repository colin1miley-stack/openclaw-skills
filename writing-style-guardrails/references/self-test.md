# Writing Style — Self-Test Checklist

## 10-Second Check (Before Delivery)

1. [ ] **No banned words?** (foster, tapestry, delve, robust, landscape, leverage, paradigm, synergy, holistic)
2. [ ] **Sentence length varies?** (Not all short, not all long)
3. [ ] **Active voice dominates?** (Can add "by zombies" test — if it works, it's passive)
4. [ ] **No setup language?** ("In conclusion", "The key takeaway", "To summarize")
5. [ ] **Sounds like I'd say this aloud?** (Read it out loud — does it sound natural?)

## 30-Second Check (For Important Content)

6. [ ] **No hedging?** (Remove all "might", "could", "perhaps", "arguably")
7. [ ] **Specific nouns and numbers?** (Replace "many" with a number, "some" with a specific group)
8. [ ] **No restating the question?** (Get straight to the answer)
9. [ ] **No summary at the end?** (If you said it well, you don't need to summarize)
10. [ ] **Headings are specific?** (Not "Key Takeaways" but "The One Thing That Changes Everything")

## Deep Check (For Published Content)

11. [ ] **Every claim has evidence?** (Number, example, or source)
12. [ ] **"You" and "your" outnumber "we" and "our"?** (Reader-focused)
13. [ ] **Paragraph length varies?** (Mix 1-sentence punchlines with 5-sentence explanations)
14. [ ] **List bullets vary in structure?** (Not all complete sentences, not all fragments)
15. [ ] **No AI-sounding phrases?** ("In the ever-changing landscape of...", "It's important to note that...")

## Score

- **15/15:** Publish immediately
- **12-14:** Quick fix, then publish
- **9-11:** Revision needed
- **<9:** Rewrite from scratch
